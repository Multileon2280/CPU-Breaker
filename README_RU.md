# CPU-Breaker (Арканоид на самодельном процессоре)

Это моя первая игра, написанная на Python с использованием библиотеки Kivy. 
Главная фишка: физика мяча рассчитывается на моем самодельном (Homemade) 32-битном процессоре (эмуляция на Python)!

## Как запустить
1. Установите Python 3.
2. Установите библиотеку Kivy:
   pip install kivy
3. Запустите игру:
   python main.py

## Управление
Водите пальцем (или мышкой) по экрану, чтобы двигать ракетку.
Разбейте все кирпичи, не дав мячу упасть!

## Технические детали
Процессор: Написан на Python с нуля. Поддерживает 32-битные регистры, математику и память.
Kivy: Отвечает за графику и интерфейс.
