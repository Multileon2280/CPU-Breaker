# CPU-Breaker (Arkanoid on a Homemade CPU)

This is my first game, written in Python using the Kivy library.
Main feature: the ball's physics is calculated on my homemade 32-bit processor (emulated in Python)!

## How to Run
1. Install Python 3.
2. Install the Kivy library:
   pip install kivy
3. Run the game:
   python main.py

## Controls
Move your finger (or mouse) across the screen to move the paddle.
Break all the bricks without letting the ball fall!

## Technical Details
CPU: Written in Python from scratch. Supports 32-bit registers, math, and memory.
Kivy: Handles graphics and UI.
